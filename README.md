# C++ project
## Requires MIL X to be installed already in order to run

Simple application that demonstrates the basic principles of defining vector-based ROI(s) within a graphic list

 - Begins with two graphics, a circle and rectangle that can be interacted with
 - once done interacting, focus the CMD window and press any key
 - The graphics are saved to a buffer and exported to `C:\testbuffer.tiff`
 - focus the CMD window and press any key
 - The buffer is loaded from disk and exported to a new graphic list that is interactable
